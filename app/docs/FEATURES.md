# Features

## Chat

- Streaming chat through `POST /chat/stream`.
- Conversation CRUD and URL-addressable conversations.
- Skill routing with explicit, session, and automatic selection.
- Agentic thinking modes for multi-step answers.
- Web search, reverse image search, OCR, STT, memory, and MCP tools.

## Generation

- Hosted image providers plus local ComfyUI/Stable Diffusion paths.
- Optional local reasoning/anime image pipelines.
- Video generation through OpenAI-compatible Sora routes.

## Desktop And Local Ops

- Electron shell for a local desktop workflow.
- Root Docker compose for core services.
- Service-specific launch scripts for GPU-heavy image services.
- RAG service tree with its own API, worker, libraries, tests, and compose file.
